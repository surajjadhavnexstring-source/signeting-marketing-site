# components/ rules

- `ui/` — buttons, inputs, cards. `sections/` — hero, feature grid, pricing table, logos, CTA, FAQ. `layout/` — header, footer, page shell.
- Components receive all text as props or from `content/`. No hard-coded copy.
- Use tokens from `styles/tokens.css` only.
- Responsive by default: check 390, 768, and 1440 widths.
- Reuse or extend an existing component before creating a new one.
